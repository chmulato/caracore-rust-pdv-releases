Primeira venda

Depois de instalar, o fluxo do balcão — no espírito de testar no próprio PC.

  1. Assistente /setup — na primeira abertura, conclua a preparação do banco (SQLite local).
  2. Login — entre com admin / admin123 (troque a senha se for usar no dia a dia).
  3. Abrir o turno — o caixa só vende com o turno aberto.
  4. Vender — registre a primeira venda. PIX do piloto: QR na tela + confirmação do operador (não é gateway automático). Fiscal deste corte: simulado / treino.

Teto: 100 vendas na vida deste banco (não por mês). Guia completo: primeiros passos.

Instalação em 4 passos

  1. Baixar — escolha NSIS, MSI ou ZIP nos cards acima.
  2. Verificar — conferir o SHA-256 (PowerShell: Get-FileHash .\arquivo -Algorithm SHA256).
  3. Instalar — guia com login e pasta de dados.
  4. Primeira venda — /setup → admin / admin123 → abrir turno → vender.

Depois do teto do piloto

Sem o limite de 100 vendas na vida deste banco, a Cara Core envia proposta da edição completa — no mesmo produto deste site.

Solicitar proposta

Os dados deste piloto ficam em %APPDATA%\caracore-pdv\.
