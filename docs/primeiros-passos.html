Este guia é do piloto Rust O Free Java do balcão (v3.2.3-free, Windows/Linux/macOS) instala e guarda dados em outro caminho. Se você quer o caixa maduro multi-plataforma, vá para pdv.caracore.com.br/download.html.

0. Escolher modalidade

Local (um PC) ou rede (vários caixas): Local e rede →

1. Baixar

Na página Formatos, escolha NSIS, MSI ou ZIP da tag v0.1.2. Confira o SHA-256 antes de executar.

2. Instalar

Opção A — Instalador NSIS (lojista)

  1. Execute CaraCore.PDV_0.1.2_x64-setup.exe (assistente em português).
  2. Siga as telas até concluir.
  3. Abra CaraCore PDV pelo menu Iniciar ou atalho criado.

Opção B — MSI (TI / empresa)

  1. Instale CaraCore.PDV_0.1.2_x64_pt-BR.msi (duplo clique ou ferramenta de deploy da sua TI).
  2. Para instalação silenciosa em rede, use o procedimento padrão de MSI da sua equipe de TI.

Opção C — ZIP portátil

  1. Extraia CaraCore-PDV-v0.1.2-windows.zip em uma pasta fixa no computador da loja.
  2. Use o atalho ou instalar-atalho.bat incluído no pacote, se disponível.
  3. Abra CaraCore PDV pelo atalho.

3. Primeira abertura — assistente /setup

Na primeira execução o programa abre a tela /setup (assistente de banco). Conclua o assistente escolhendo SQLite local. Isso grava setupConcluido na configuração.

  1. Se a tela pedir preparação do banco, avance o assistente até finalizar.
  2. Depois você cai na tela de login.

Login de primeiro acesso (piloto)

Campo Valor
Usuário admin
Senha admin123

Essa senha é a do bootstrap do piloto. Troque depois no cadastro de usuários se a loja for usar o programa no dia a dia. Não é a senha admin/admin do Free Java.

4. Operar

Após o login, a tela de vendas fica disponível. Caixa, produtos e relatórios acessam-se pelo menu principal.

Onde ficam os arquivos — pasta diferente do Java

Rust ≠ Java no disco O piloto Rust usa %APPDATA%\caracore-pdv\. O Free Java usa %APPDATA%\caracore\. Apagar uma pasta não limpa a outra. Não misture backups.
